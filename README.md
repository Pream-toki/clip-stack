# Clip stack

Keeps the last 15 **text** copies. Click one in the tray to put it back on the clipboard.

## Setup

Python 3 → double-click `START.bat` → brown clipboard icon in the tray.

## Use

1. Copy text as usual (Ctrl+C).
2. Right-click the icon → click an old snippet.
3. Paste (Ctrl+V).

**Careful**

- Images / files are ignored.
- Anything you copy (including passwords) sits in that menu until you **Clear** or **Quit**. Don’t leave it open on a shared PC with secrets in the stack.
- **OFF** stops recording; what’s already there stays until Clear.
- **Start with Windows** is optional.
